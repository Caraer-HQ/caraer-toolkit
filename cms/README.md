# CMS Library

Reusable CMS material follows these levels:

1. `defaults/` — brand and website-wide style defaults.
2. `components/` — single reusable building blocks.
3. `sections/` — composed component groups such as heroes, FAQs, and calls to action.
4. `page-templates/` — complete page layouts.
5. `site-starters/` — coordinated defaults, navigation, and page templates.

Every reusable item needs a short README, its native CMS structure or source content, a preview, required inputs and dependencies, responsive verification notes, and a clear statement of whether it is a copied starter or a linked native component.
