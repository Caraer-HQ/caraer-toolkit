# Caraer Toolkit

Reusable Caraer documentation, object templates, CMS patterns, email templates, and OpenClaw skills for customers and implementation partners.

## Contents

- `docs/` — customer documentation and editable diagram sources.
- `object-templates/` — composable object, property, relation, and trait patterns.
- `cms/` — defaults, components, sections, page templates, and site starters.
- `email-templates/` — reusable customer communication templates.
- `skills/` — reusable OpenClaw procedures. See its README before installing them on another host.

## Before use

Choose only the material that fits the target portal. Keep customer records, credentials, access configuration, and customer-specific overrides outside this toolkit.

See each skill or template README for its dependencies and verification steps.

## Source of truth

The Caraer team maintains the source toolkit privately. This repository is a generated public mirror: contributions and release requests should be raised with Caraer rather than edited directly in the mirror.
