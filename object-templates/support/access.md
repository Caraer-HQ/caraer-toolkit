# Support Suite Access

Access is granted through teams. Support records contain customer context and
may contain personal or operational information.

## Object access

| Team | Ticket |
| --- | --- |
| General employee | Read assigned tickets only; comment when assigned. |
| Recruitment | Read/create/update recruitment-related tickets. |
| HR | Read/create/update HR-related tickets. |
| Sales | Read/create/update customer and partner tickets within scope. |
| Marketing | Read marketing-related tickets; no default customer support write. |
| Hiring managers | Read/update assigned recruitment or hiring tickets. |
| Management | Full access and administration. |

## Assignment

Ticket visibility follows the owning suite, assigned team, ticket owner, and
explicit record assignment. Team membership alone does not expose unrelated
customer tickets.
