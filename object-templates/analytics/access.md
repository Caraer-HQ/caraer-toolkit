# Analytics Suite Access

Access is granted through teams. Users must be assigned to the appropriate
team; do not grant object permissions directly to individual users by default.

## Suite access

| Team | Access |
| --- | --- |
| General employee | No default access. |
| Recruitment | Read recruitment dashboards and create/update recruitment views. |
| HR | Read recruitment and people analytics; manage HR reports. |
| Sales | Read and manage sales and customer analytics. |
| Marketing | Read and manage marketing and campaign analytics. |
| Hiring managers | Read assigned recruitment analytics only. |
| Management | Full read access and report administration. |

## Object scope

Analytics views must respect the source-suite permissions. A team cannot gain
access to restricted source records through an analytics view.
