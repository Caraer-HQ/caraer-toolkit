# Onboarding Suite Access

Access is granted through teams. Onboarding records are shared only with the
teams responsible for implementation, customer success, partner delivery, or
oversight.

## Object access

| Team | Access |
| --- | --- |
| General employee | No default access; read assigned tasks only. |
| Recruitment | Read recruitment-related onboarding records. |
| HR | Read and manage employee onboarding records. |
| Sales | Read customer and partner onboarding status; update commercial handoff fields. |
| Marketing | Read approved public/project status only. |
| Hiring managers | Read assigned hiring onboarding records. |
| Management | Full access and administration. |

## Sensitive data

Internal notes and operational handoff details are restricted to the owning
team, Sales where commercially necessary, HR for employee onboarding, and
Management.
