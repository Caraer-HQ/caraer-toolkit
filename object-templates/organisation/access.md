# Organisation Suite Access

Access is granted through teams. Organisation structure is broadly readable,
while changes to the canonical hierarchy are restricted.

## Object access

| Team | Company | Target | Account | Partner | Location | Department | Business Unit |
| --- | --- | --- | --- | --- | --- | --- | --- |
| General employee | Read | No default access | Read limited context | No default access | Read | Read | Read |
| Recruitment | Read | Read | Read relevant accounts | No default access | Read | Read | Read |
| HR | Read | No default access | Read | No default access | Read | Full access | Read |
| Sales | Full access | Full access | Full access | Full access | Full access | Read/update relevant structure | Read/update relevant structure |
| Marketing | Read | Read | Read limited context | No default access | Read | Read | Read |
| Hiring managers | Read relevant organisations | Read relevant targets | Read relevant accounts | No default access | Read | Read relevant departments | Read relevant units |
| Management | Full access | Full access | Full access | Full access | Full access | Full access | Full access |

## Suite administration

Sales and Management administer organisation records. HR may administer
employee-related department structure; other teams do not change canonical
organisation hierarchy by default.
