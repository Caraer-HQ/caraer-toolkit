# Campaigns Suite Access

Access is granted through teams. Campaign performance may contain commercial,
audience, and spend data, so write access is restricted to responsible teams.

## Object access

| Team | Meta Campaign | Meta Ad Set | Meta Ad |
| --- | --- | --- | --- |
| General employee | No default access | No default access | No default access |
| Recruitment | Read campaign data relevant to recruitment | Read relevant ad-set data | Read relevant ad data |
| HR | No default access | No default access | No default access |
| Sales | Read campaign performance relevant to sales | Read relevant ad-set data | Read relevant ad data |
| Marketing | Full access | Full access | Full access |
| Hiring managers | Read assigned recruitment campaigns | Read assigned ad sets | Read assigned ads |
| Management | Full access and administration | Full access and administration | Full access and administration |

## Sensitive fields

Spend, leads, audience performance, and raw insights follow the same access
scope as the parent campaign. Marketing and Management may administer campaign
views and provider mappings.
