# Suites

A **Suite** is a named collection of access settings that can be assigned consistently to Users or Teams.

Suites are useful when several people need the same type of access. For example, a Support Suite might allow access to customer Records, Activities, and support Views without granting administrative control over the data model.

## Use Suites carefully

- name a Suite after its purpose;
- include only the access needed for that purpose;
- review the Suite when a responsibility changes;
- check whether assigning it adds access to sensitive information.

The available Suites and the way they are assigned depend on your Caraer workspace.
