# Databases

Latenode can use databases as part of a Scenario. A database can store information that a Scenario needs to read, create, update, or search.

Database use may include:

- storing application data;
- looking up information before an action;
- saving results from a Scenario;
- querying a collection;
- providing information to an AI Agent or RAG process.

## Plan database access

Before connecting a database, decide what information the Scenario needs and who should be allowed to change it. Test queries with sample data before using them in a live process.

See the official Latenode sections for [Database basics](https://documentation.latenode.com/databases/database/database-basics) and [RAG databases](https://documentation.latenode.com/databases/rag-database/ai-data-storage).
