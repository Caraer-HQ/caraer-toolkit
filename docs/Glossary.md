# Caraer Glossary

Use this glossary for the main terms used in the customer documentation.

## Action

A Trait that lets a Record represent an action or interaction, such as a call, website event, or follow-up action.

## Activity

A Record that describes work, communication, or an event connected to the work your team is doing.

## Analytics

A Trait that supports reporting and analysis of Records.

## Automation

A repeatable process that starts from a Trigger, checks any Conditions, and performs an Action.

## Candidate

An Extended Object that can represent a person in a pre-employment context.

## Employee

An Extended Object that can represent a person in an employment context.

## Event

A Trait that lets a Record represent a scheduled or time-based event.

## Extended Object

An Object that adds a specialised context to an existing Record without creating a duplicate of that Record.

## Filter

A condition that limits which Records are shown in a View.

## Flow

A Trait that lets Records move through stages in a process.

## Message

A Trait that lets a Record represent a message or other communication.

## Morphing

Moving a Record from one Extended Object to another while keeping the same underlying Record identity. Morphing changes the active context; it does not create a duplicate Record.

## Object

A definition of a kind of thing that Caraer manages, including its Records, Properties, and optional Traits.

## Object family

A Primary Object together with its related Extended Objects and the rules for using them together.

## Page

A Trait that lets Records behave as pages or other published content.

## Plan

A Record that describes a package, service level, or other offering. A Plan can be connected to a Company or Contract through a Relation.

## Primary Object

The original Object in an object family. It provides the underlying identity and native Properties.

## Property

Information stored on a Record, such as a name, status, date, or amount.

## Record

One individual item created from an Object, such as one Company, Contract, or Task.

## Relation

A named connection between independently existing Records, such as a Company that works with an Employee.

## Shared Property

A Property from an Extended Object that is also shown in another relevant context.

## Table

A Trait that lets people view and manage Records in rows and columns.

## Task

A Trait that lets a Record represent work that needs to be completed.

## Trigger

The situation that starts an Automation.

## Trait

A reusable capability attached to an Object, such as Table, Page, Task, or Analytics.

## User

A person who can sign in to Caraer and use the access granted to them.

## View

A saved or temporary way of displaying Records, often with selected columns, sorting, grouping, and Filters.
