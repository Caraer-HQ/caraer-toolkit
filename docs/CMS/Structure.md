# Structure

The CMS **Structure** defines how customer-facing content is organised. It can include pages, sections, navigation, URLs, and relationships between content items.

The Structure page is available at `/structure`.

Each item can represent a page or section in the website structure. Items may include a label and URL, and can be reordered using drag and drop.

## A clear structure

Plan the structure before adding many pages:

- decide which content belongs at the top level;
- group related pages together;
- use clear names for navigation items;
- keep important content easy to find;
- avoid duplicate pages with overlapping purposes.

The exact structure depends on your website or publication setup.
