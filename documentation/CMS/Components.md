# Components

CMS **Components** are reusable pieces of page content. A Component can help teams build pages consistently without recreating the same layout each time.

The Components page is available at `/components`.

Examples include:

- headings and text sections;
- images or media blocks;
- buttons and links;
- forms;
- cards or lists;
- reusable page sections.

## Good Component practice

- give Components clear names;
- use consistent content and spacing;
- keep reusable Components general enough for their purpose;
- review a Component before changing it if it is used on multiple pages.
