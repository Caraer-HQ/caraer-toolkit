# Website Settings

**Website Settings** control configuration that applies across the website rather than to one individual page. The Website Settings page is available at `/website-settings`.

Depending on the workspace, Website Settings may include:

- website name and identity;
- domain and website address;
- logo, colours, and other branding;
- default language or locale;
- navigation defaults;
- publishing and access defaults.

Changes to Website Settings can affect multiple pages. Review changes carefully before publishing them.
