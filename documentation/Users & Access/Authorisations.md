# Authorisations

An **Authorisation** is the permission that allows a User or Team to perform an action within a Scope.

Examples of actions include:

- view;
- create;
- edit;
- connect through a Relation;
- run an Automation;
- manage settings.

## Review an Authorisation

When checking an Authorisation, ask:

1. Who receives it?
2. What Scope does it cover?
3. What action does it allow?
4. Is the access still needed?

Give people the access they need for their work and no more. Review Authorisations when someone joins, leaves, changes role, or when a new Object or Automation is introduced.

If you are unsure about an Authorisation, contact your Caraer administrator or representative.
