# Scopes

A **Scope** describes the area of Caraer information or action to which access applies.

Scopes can be used to separate access to:

- an Object or type of Record;
- a specific Property or group of information;
- a Relation;
- a View or Activity;
- an Automation or administrative setting.

## Keep Scopes understandable

Use names that explain what the access covers. A person reviewing access should be able to understand a Scope without knowing how it was configured.

Scopes are often combined in a Suite or assigned through a Team. The exact Scope options depend on the workspace.
