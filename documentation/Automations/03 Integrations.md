# Integrations

Integrations connect Latenode to external applications and services. An integration can provide Trigger Nodes, Action Nodes, or both.

Common integration categories include:

- communication services;
- email and productivity tools;
- CRM and sales systems;
- databases and spreadsheets;
- AI models and services;
- custom APIs through HTTP Requests.

## Choose an integration

Choose an integration based on the event you need to receive and the action you need to perform. Check the available Nodes before designing the whole Scenario.

If a ready-made integration or action is not available, Latenode may support an HTTP Request or JavaScript Node. These options require more care and testing.

See the current [Latenode integrations catalogue](https://documentation.latenode.com/integrations).
