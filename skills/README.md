# Public Skills

These skill packages are loaded directly by OpenClaw from this directory. They are reusable Caraer procedures published for customers and implementation partners.

- [Caraer Credential Vault Handoff](caraer-credential-vault-handoff/SKILL.md) — safely provision a provider credential into an existing app installation, including OpenClaw protected handoffs.

`caraer-cms` and `caraer-object-schema` currently include Caraer-host-specific local source paths. They are safe to read as procedure documentation, but before installing them on another host, replace those paths with the client's toolkit location and validate in a clean client workspace. A portable revision will follow.
